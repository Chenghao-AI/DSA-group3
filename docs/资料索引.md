## 阅读顺序建议

1. ch1 四条原则（封装变化 / 多用组合少用继承 / 针对接口编程 / 开放-关闭）→ 半小时垫底
2. 通读 HeadFirst ch3，不停顿不查
3. 合上书白纸默画 p.91 类图 + 手写咖啡计价 → 这是"会了"的自检线
4. GoF 4.4 逐条对照（意图/动机/适用性/结构/参与者/协作/效果/实现）
5. 责任链改以 GoF 5.1 为主干（HeadFirst 只有 2 页，不够讲）
6. 横向对比：装饰器 vs 责任链 vs 代理
7. 落到真实框架源码（OkHttp / Netty / Spring Security / Java I/O）

## 一句记牢

装饰器与责任链的类图几乎同构（都是"持有同类型引用"），语义差别只有一条：

> **装饰器是"都执行"（层层加壳），责任链是"到谁为止"（有人处理就截断）。**
