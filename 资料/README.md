# 资料目录说明

本目录存放教材与课件。**原始文件不入库**，这里只放说明。

## 本地应有的文件

| 文件 | 大小 | 入库 |
|---|---|---|
| `HeadFirst设计模式.pdf` | 127 MB | 否 |
| `设计模式：可复用面向对象软件的基础.pdf`（GoF） | 25 MB | 否 |
| `设计模式-翻转课堂.pptx`（老师要求） | 49 KB | 否 |
| `11.23初步介绍.pptx` | 740 KB | 否 |

## 为什么不传上来

1. **GitHub 单文件硬上限 100 MB**，HeadFirst 那份 PDF 是 127 MB，直接推不上去，会报 `this exceeds GitHub's file size limit of 100.00 MB`。
2. 整个目录 154 MB，9 个人各 clone 一次就是 1.4 GB 流量，纯属浪费。
3. 教材有版权，公开仓库不适合放。

## 从哪拿

见班级群文件 / 群公告里的网盘链接。本地已有的同学直接在群里发一份即可。

## 看书时的定位

两份 PDF 都是**扫描版、没有文本层**，`Ctrl+F` 搜关键词搜不到，只能按页翻。
页码对照表见 `docs/资料索引.md`（如果该文件还在的话）。
